Are you tired of building a starter base to research bots and blueprints only to tear it down? Mega Bot Start lets you start with construction bots in a Vanilla+ way. You'll start with:

* Power Armor mk.2 or Mech Armor
* 50 construction robots
* 4 personal roboports
* Fusion reactors
* Batteries
* More, as the user can customize.

Optional additions include:
* Up to 500 robots
* Faster worker speed research unlocked.
* Shield generators
* Laser defenses

Compatible with mods including Bob's Warfare/Logistics/Personal Equipment and Krastorio 2. Enabling those mods will give different armors and a different equipment grid.

No technology is unlocked. No existing items are changed. No new items are added.

Originally forked from [Peppe Bot Start](https://mods.factorio.com/mods/Peppe/PeppeBotStart), then again from [OneBit](https://mods.factorio.com/mods/onebit/AdequateBotStart). Changed from modular armor to Power armor Mk.2 and replaced solar panels with fusion reactors.
